# ⭐ منصة ستار فل بالعربي (Starfall Arabic Games)

منصة تعليمية تفاعلية حديثة ومتكاملة للأطفال في مرحلة ما قبل المدرسة والسنوات الأولى من المرحلة الابتدائية (من عمر 1 إلى 7 سنوات). تم تصميمها وتطويرها وفق أحدث مبادئ هندسة البرمجيات وتجربة المستخدم للأطفال (Child UX)، وتصميم الألعاب التعليمية (Educational Game Design).

---

## 🌟 1. الرؤية وفكرة المنصة

تهدف المنصة إلى نقل الطفل إلى **عالم تعليمي متكامل وممتع** يجمع بين:
- التعلم النشط القائم على اللعب والاستكشاف البصري.
- تنمية التفكير المنطقي والرياضي، وحل المشكلات، وإدراك الأنماط.
- إتقان الحروف والأرقام والمفردات باللغتين العربية والإنجليزية.
- تنمية الذاكرة البصرية، والإدراك المكاني، والذكاء العاطفي والتواصل الإيجابي.
- بيئة رقمية آمنة 100%، خالية من الإعلانات ومن أدوات التتبع أو النوافذ المشتتة.

## 🎮 2. مكتبة الألعاب التعليمية (18 لعبة تفاعلية كاملة)

تم تنظيم الألعاب ضمن **6 مسارات تربوية كبرى**:

### 🔢 أ. مسار الأرقام والرياضيات (Numbers & Math)
1. **تطابق الأرقام (`numbers`)**: مطابقة الذاكرة مع نقاط العد ودعم الأرقام العربية (١، ٢، ٣) والإنجليزية (1، 2، 3).
2. **العد والمقارنة بين الكميات (`counting-compare`)**: عد المجموعات التفاعلية وتحديد الأكبر والأصغر والمتساوي (> < =).

### 🔤 ب. مسار الحروف واللغة (Letters & Phonics)
3. **تطابق الحروف العربية (`arabic-letters`)**: مطابقة بطاقات الحروف الهجائية الـ 12 مع أمثلة للكلمات.
4. **تطابق الحروف الإنجليزية (`english-letters`)**: مطابقة الحروف الكبيرة مع الصغيرة (A - a) أو المتماثلة.

### 📝 ج. مسار الكلمات والقراءة (Words & Vocabulary)
5. **الحروف والكلمات العربية (`arabic-words`)**: ربط كل حرف عربي بالكلمة والصورة التي تبدأ به (أ 🦁 أسد).
6. **الكلمات الإنجليزية بالصور (`english-words`)**: مطابقة الكلمات الشائعة باللغة الإنجليزية مع الرسوم والترجمة العربية.

### 🧩 د. مسار الذاكرة والألغاز (Memory & Puzzles)
7. **تطابق الصور والذاكرة (`images`)**: لعبة ذاكرة بصرية كلاسيكية بأيقونات ورسوم ملونة ومبهجة.
8. **ترتيب الصور - قطعتان (`puzzle-2`)**: بازل تمهيدي لتركيب نصفي الصورة للحيوانات والمركبات.
9. **ترتيب الصور - أربع قطع (`puzzle-4`)**: بازل شبكة 2x2 لتنمية الإدراك المكاني وتجميع أرباع الصورة.
10. **فرز الأشكال والألوان (`color-shape-sorter`)**: تصنيف العناصر في سلال بحسب اللون أو الشكل الهندسي.

### 🔄 هـ. مسار التفكير المنطقي (Logic & Thinking)
11. **التعرف على العلاقات (`relations`)**: ربط الأشياء المترابطة واقعياً في عمودين تفاعليين (المضرب والكرة، القفل والمفتاح).
12. **المعكوسات والمتضادات (`opposites`)**: أسئلة تفاعلية مصورة لتعلم المفاهيم المتضادة (فوق/تحت، حار/بارد، كبير/صغير).
13. **إكمال النمط والتسلسل (`pattern-complete`)**: استنتاج القاعدة المنطقية واختيار الشكل التالي المكمل للتسلسل.
14. **اكتشاف العنصر المختلف (`odd-one-out`)**: تدريب دقة الملاحظة والبحث عن العنصر الشاذ مع إيضاح السبب.

### 🌸 و. مسار العلوم والطبيعة والمشاعر (Science & Social Skills)
15. **فصول السنة الأربعة (`seasons`)**: مسابقة الفصول الأربعة مع التفسيرات العلمية المبسطة.
16. **الليل والنهار (`day-night`)**: التمييز والتصنيف بين أنشطة وظواهر النهار المشمس والليل الهادئ.
17. **الحيوانات وبيئاتها وغذاؤها (`animal-habitats`)**: مساعدة الحيوان في العثور على موطنه الطبيعي وغذائه المفضل.
18. **التعرف على المشاعر والتواصل (`emotions-kids`)**: فهم وتسمية المشاعر الإنسانية (سعيد، حزين، متفاجئ، هادئ) وتنمية التعاطف.

## 🛠️ 3. التقنيات المستخدمة (Tech Stack)

- **React 19**: أحدث إصدار من مكتبة بناء الواجهات.
- **TypeScript**: أمان كتابة الأنماط والأنواع البرمجية لمنع الأخطاء أثناء التطوير.
- **Vite 6**: حزمة تشغيل وبناء سريعة وفعالة.
- **React Router v7**: توجيه المسارات المباشرة وإدارة صفحات المنصة (SPA).
- **Tailwind CSS v4**: تنسيقات بصرية متجاوبة عالية التباين، مخصصة للأطفال.
- **Web Audio API**: مصنّع صوتي مدمج بدون ملفات وسائط خارجية لتوليد نغمات تشجيعية فورية.
- **Canvas Confetti**: احتفالات بصرية وقصاصات ملونة عند إكمال التحديات.
- **Vitest & React Testing Library**: اختبارات آلية شاملة للمنطق والبيانات والترجمة.

## 🚀 5. التثبيت والتشغيل المحلي

### المتطلبات
- **Node.js**: الإصدار 18 أو 20 أو 22.
- **npm**: مدير الحزم الافتراضي.

```bash

git clone https://github.com/mfk2252/starfall-arabic-games.git
cd starfall-arabic-games

# 2. تثبيت الاعتماديات
```

## ➕ 7. طريقة إضافة لعبة جديدة (Adding a New Game)

1. أضف معرف اللعبة الجديد إلى نوع `GameId` في `src/types.ts`.
2. سجّل اللعبة مع بياناتها وأيقونتها وفئتها في مصفوفة `GAMES_LIST` في `src/data/games.ts`.
3. (اختياري) ضع أسئلتها وبياناتها في `src/data/gameContent.ts`.
4. أنشئ مكون اللعبة في `src/components/games/YourGameName.tsx` مستخدماً `GameHeader` و`WinCelebration` ومساعد الصوت `sound`.
5. أضف حالة اللعبة في دالة `renderGame` داخل `src/pages/GamePlayPage.tsx`.
6. أضف اختباراً للعبة في `src/test/`.

---

## 🌐 8. طريقة إضافة لغة جديدة (Adding a New Language)

1. أضف رمز اللغة في `Language` داخل `src/i18n/types.ts` (مثال: `'fr'`).
2. أنشئ ملف ترجمة جديد `src/i18n/fr.ts` يطابق واجهة `Translations`.
3. استورد الملف في `src/i18n/LanguageContext.tsx` وحدد اتجاه الواجهة (`ltr` أو `rtl`).

## ☁️ 9. النشر على Vercel (Deployment to Vercel)

المشروع مهيأ وجاهز للنشر المباشر بنقرة واحدة عبر Vercel:

1. ارفع المشروع إلى مستودع GitHub الخاص بك.
2. توجه إلى [Vercel](https://vercel.com) واختر **Add New Project** ثم استورد المستودع.
3. الإعدادات الافتراضية:
   - **Framework Preset**: Vite
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
4. تم تضمين ملف `vercel.json` لإعادة توجيه المسارات المباشرة إلى `/index.html` تلقائياً لمنع أي أخطاء 404 عند تحديث الصفحات الداخلية.
