# ستار فل بالعربي - ألعاب تعليمية للأطفال

## نظرة عامة
مجموعة من الألعاب التعليمية التفاعلية للأطفال من عمر 1-7 سنوات، مصممة لتعليم الأرقام والحروف والمفاهيم الأساسية بطريقة ممتعة وتفاعلية.

## الألعاب المتوفرة
1. **تطابق الأرقام** - لعبة ذاكرة لتعلم الأرقام من 1-8
2. **تطابق الحروف الإنجليزية** - تعلم الحروف الإنجليزية
3. **تطابق الحروف العربية** - تعلم الحروف العربية
4. **الحروف والكلمات العربية** - ربط الحروف بالكلمات
5. **الكلمات الإنجليزية** - تطابق الكلمات الإنجليزية
6. **تطابق الصور** - لعبة ذاكرة بصرية
7. **التعرف على العلاقات** - ربط الأشياء المترابطة
8. **المعكوسات** - تعلم المفاهيم المتضادة
9. **ترتيب الصور - قطعتان** - بازل بسيط
10. **ترتيب الصور - أربع قطع** - بازل متقدم
11. **فصول السنة** - تعلم فصول السنة الأربعة
12. **الليل والنهار** - التمييز بين الليل والنهار

## كيفية استضافة الألعاب على GitHub Pages

### الخطوة 1: إنشاء مستودع GitHub
1. اذهب إلى [GitHub.com](https://github.com) وقم بتسجيل الدخول
2. انقر على "New repository"
3. اختر اسم المستودع مثل "starfall-arabic-games"
4. تأكد من أن المستودع عام (Public)
5. انقر على "Create repository"

### الخطوة 2: رفع الملفات
1. قم بتحميل جميع ملفات المشروع إلى المستودع:
   - `index.html` (الصفحة الرئيسية)
   - مجلد `css/` (ملفات التنسيق)
   - مجلد `js/` (ملفات JavaScript)
   - مجلد `games/` (ملفات الألعاب)
   - مجلد `assets/` (الصور والأيقونات)

### الخطوة 3: تفعيل GitHub Pages
1. اذهب إلى إعدادات المستودع (Settings)
2. انتقل إلى قسم "Pages" في الشريط الجانبي
3. في "Source"، اختر "Deploy from a branch"
4. اختر "main" branch و "/ (root)"
5. انقر على "Save"
6. ستحصل على رابط مثل: `https://username.github.io/starfall-arabic-games`

## كيفية تضمين الألعاب في ووردبريس.كوم (الخطة المجانية)

### الطريقة 1: الروابط المباشرة
نظرًا لقيود الخطة المجانية، أفضل طريقة هي إنشاء روابط مباشرة للألعاب:

```html
<a href="https://username.github.io/starfall-arabic-games/games/numbers.html" target="_blank">
  لعبة تطابق الأرقام
</a>
```

### الطريقة 2: استخدام كتلة HTML المخصصة (إذا كانت متاحة)
إذا كانت كتلة HTML المخصصة متاحة في خطتك:

```html
<div style="text-align: center; padding: 20px;">
  <h3>ألعاب ستار فل بالعربي</h3>
  <div style="display: grid; grid-template-columns: repeat(auto-fit, minmax(200px, 1fr)); gap: 15px;">
    <a href="https://username.github.io/starfall-arabic-games/games/numbers.html" 
       target="_blank" 
       style="background: #4fc3f7; color: white; padding: 15px; border-radius: 10px; text-decoration: none;">
      🔢 تطابق الأرقام
    </a>
    <a href="https://username.github.io/starfall-arabic-games/games/arabic-letters.html" 
       target="_blank" 
       style="background: #81c784; color: white; padding: 15px; border-radius: 10px; text-decoration: none;">
      أ تطابق الحروف العربية
    </a>
    <!-- إضافة المزيد من الألعاب -->
  </div>
</div>
```

### الطريقة 3: إنشاء صفحة منفصلة
1. أنشئ صفحة جديدة في ووردبريس بعنوان "الألعاب التعليمية"
2. أضف وصف للألعاب
3. أضف قائمة بالروابط المباشرة لكل لعبة

## نصائح للتحسين

### 1. تحسين الأداء
- تأكد من ضغط الصور في مجلد `assets/`
- استخدم أدوات ضغط CSS و JavaScript

### 2. إضافة المزيد من الألعاب
- انسخ أي ملف لعبة موجود
- عدّل المحتوى والمنطق حسب الحاجة
- أضف رابط اللعبة الجديدة في `index.html`

### 3. تخصيص التصميم
- عدّل ألوان CSS في `css/main.css`
- أضف أيقونات جديدة في مجلد `assets/`
- غيّر الخطوط من Google Fonts
