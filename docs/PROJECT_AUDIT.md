## 2. أهم المشكلات والمخاطر التي تم تحديدها (Identified Risks & Gaps)
1. **انعدام نظام التوجيه (No Routing)**: كان المشروع السابق مجرد ملفات منفصلة أو تنبيهات `alert()`، دون توجيه عنوان URL مباشر أو تجربة SPA حقيقية.
2. **انعدام التعدد اللغوي المنظم (No Centralized i18n)**: النصوص كانت مدمجة في الشيفرة، مع صعوبة التحويل بين اللغات واتجاه الواجهة (RTL/LTR).
3. **محدودية التنوع التعليمي (Curriculum Breadth)**: كانت الألعاب مقتصرة في الغالب على المطابقة الذاكرية، وغابت مهارات بالغة الأهمية مثل:
   - تمييز الأنماط والتسلسل المنطقي.
   - اكتشاف العنصر الشاذ (Odd-One-Out).
   - بيئات الحيوانات والغذاء.
   - العد التفاعلي والمقارنة الرياضية للأطفال.
   - تصنيف الأشكال والألوان.
   - الذكاء العاطفي والمشاعر البسيطة.
4. **تجريد البيانات (Hardcoded Game Data)**: غياب هيكل بيانات موحد للأسئلة والمستويات والتعليمات.
5. **إمكانية الوصول والتحكم للأطفال (Child UX & Accessibility)**: الحاجة لنظام صوتي بدون ملفات خارجية ثقيلة، وإمكانية كتم الصوت، وأزرار لمس كبيرة، وتغذية بصرية مبهجة تشجع الطفل دون إحباطه.

## 3. البنية التقنية المقترحة (Target Architecture)
- **Framework**: React 19 + TypeScript + Vite.
- **Routing**: `react-router-dom` مع مسارات مستقلة (`/`, `/games`, `/categories`, `/categories/:categoryId`, `/games/:gameId`, `/progress`, `/about`).
- **Styling**: Tailwind CSS v4 + فئات تصميم مخصصة للأطفال، تباين عالي، خط Cairo للغة العربية، ودعم تام لـ RTL / LTR.
- **Audio**: Web Audio API Synthesizer (أصوات تفاعلية لطيفة، تشجيع، نقرات، موسيقى نصر خفيفة).
- **i18n Engine**: نظام ترجمة مركزي خفيف ومفصول يدعم العربية (افتراضياً) والإنجليزية، مع تبديل تلقائي للـ `dir` و`lang`.
- **Deployment**: Vercel SPA جاهز مع `vercel.json` لإعادة توجيه المسارات المباشرة.
- **Testing**: Vitest + React Testing Library + JSDOM.

## 4. قائمة الألعاب المقررة والمطورة
### الألعاب المنقولة والمطورة (12 لعبة):
1. **تطابق الأرقام (`numbers`)**: أرقام 1-8 مع تبديل الأرقام العربية/الإنجليزية ودعم نقاط العد.
2. **تطابق الحروف العربية (`arabic-letters`)**: 12 حرفاً هجائياً مع كلمات توضيحية.
3. **تطابق الحروف الإنجليزية (`english-letters`)**: الحروف الإنجليزية الكبيرة والصغيرة.
4. **الحروف والكلمات العربية (`arabic-words`)**: ربط الحروف بالصور والكلمات.
5. **الكلمات الإنجليزية (`english-words`)**: ربط الكلمات بالصور والمعاني.
6. **تطابق الصور (`images`)**: ذاكرة بصرية مع أيقونات ملونة وجذابة.
7. **التعرف على العلاقات (`relations`)**: ربط المضرب والكرة، القفل والمفتاح، الفرشاة والألوان...
8. **المعكوسات (`opposites`)**: مفاهيم فوق/تحت، حار/بارد، كبير/صغير، سريع/بطيء...
9. **ترتيب الصور - قطعتان (`puzzle-2`)**: بازل نصفي الصورة للحيوانات والمركبات.
10. **ترتيب الصور - أربع قطع (`puzzle-4`)**: بازل شبكة 2x2 لتجميع الصورة.
11. **فصول السنة (`seasons`)**: مسابقة الفصول الأربعة مع التفسيرات.
12. **الليل والنهار (`day-night`)**: تصنيف الأنشطة والظواهر الطبيعية.

### الألعاب الجديدة المضافة ذات القيمة التعليمية المضافة (6 ألعاب جديدة):
13. **إكمال النمط وتسلسل الأشكال (`pattern-complete`)**: إدراك النمط المنطقي واختيار الشكل المكمل.
14. **اكتشاف العنصر المختلف (`odd-one-out`)**: تدريب الملاحظة والتمييز البصري بين مجموعات العناصر المتشابهة.
15. **الحيوانات وبيئاتها وطعامها (`animal-habitats`)**: ربط الحيوان بموطنه (البحر، الغابة، القطب، الصحراء) وغذائه.
16. **العد والمقارنة بين الكميات (`counting-compare`)**: عد الأشياء والمقارنة بين الأكبر والأصغر واليساوي.
17. **فرز وتصنيف الأشكال والألوان (`color-shape-sorter`)**: تصنيف العناصر في السلال المناسبة حسب اللون أو الشكل الهندسي.
18. **التعرف على المشاعر والتواصل الاجتماعي (`emotions-kids`)**: التعرف على تعابير الوجه (سعيد، حزين، متفاجئ، هادئ) وتنمية الذكاء العاطفي.

1. إعداد مسارات React Router وبنية الصفحات.
2. بناء نظام الترجمة i18n (العربية والإنجليزية) وإدارة الاتجاه (RTL/LTR).
3. هيكلة مجلد البيانات `src/data/` لجميع الألعاب والأسئلة.
4. بناء المكونات المشتركة وتوحيد تجربة الطفل (GameCard, GameShell, ScoreBoard, AudioToggle).
5. دمج وتطوير الألعاب الـ 12 السابقة في البنية الحديثة.
6. تنفيذ الألعاب الـ 6 الجديدة بالكامل مع منطقها وشروط الفوز واختباراتها.
7. بناء صفحات الفئات، صفحة كل الألعاب، صفحة لوحة الإنجازات والتقدم مع إمكانية إعادة التعيين.
8. إنشاء الاختبارات الآلية (Vitest) والتحقق من سلامة البناء والأداء.
9. التوثيق المعماري وتحديث README.
